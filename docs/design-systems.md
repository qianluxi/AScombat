# 设计系统：选择 / 信任 / 真相引擎（Design Systems）

> 如果后续要做**互动小说**或 **AI 世界模拟**，本文件定义规则层。
> 若只做纯小说，本文件用于保证"选择"在剧情中始终存在张力。

## 1. 世界状态（World State）

模拟器不保存"剧情结果"，而保存一组**状态量**，事件在此之上涌现：

```json
{
  "relations": { "fire_water": -40, "fire_neutral": 20, "fire_windlight": 10 },
  "resources": { "fire_water_scarcity": 0.7, "water_fuel_scarcity": 0.6 },
  "technology": { "steam_engine": 0.5, "steam_pump": 0.0, "military_steam": 0.1 },
  "war_risk": 0.4,
  "public_opinion": { "fire": 0.5, "water": 0.5 },
  "historical_awareness": 0.2
}
```

## 2. 选择系统（Choice）

玩家/主角在剧情中不断面对**没有标准答案**的选择，每次选择同时改动多个状态：

| 选择 | 增益 | 代价 |
|---|---|---|
| **公开档案**（真相 vs 稳定） | +历史认知、+记事阁信任 | -社会稳定、+战争风险 |
| **公开蒸汽机**（技术公开 vs 保密） | +生产力、+国际合作 | +军事扩散风险 |
| **帮助火盟 / 帮助水盟** | +对应阵营关系 | -另一方关系 |
| **帮助风光系** | +第三方关系、+大学声望 | 触怒两盟 |
| **是否相信某份档案** | 影响后续可选项 | —— |

> **铁律**：玩家**永远无法获得 100% 确定的信息**（对应"多义性"原则）。任何选择都不是"正确选项"。

## 3. 信任矩阵（Trust Matrix）

**不要做成单一"好感度"。** 每个势力对主角的关系拆成五个维度：

```json
{
  "faction": "notegate/记事阁",
  "trust": 90,
  "interest_alignment": 20,
  "political_relation": -30,
  "ideology": 40,
  "public_reputation": 15
}
```

- `trust` 信任（你是否可信）
- `interest_alignment` 利益一致
- `political_relation` 政治关系（阵营立场）
- `ideology` 意识形态契合
- `public_reputation` 公开声望

**用途示例**：一个组织可以**信任你（90）却在政治上敌视你（-30）**——这比"好感度系统"更贴近本项目。

### 初始矩阵（提案）
| | 火盟 | 水盟 | 风光系 | 大学 | 记事阁 |
|---|---|---|---|---|---|
| 火盟 | — | -40 | +10 | +20 | -10 |
| 水盟 | -40 | — | +10 | +20 | -20 |
| 风光系 | +10 | +10 | — | +40 | +30 |
| 大学 | +20 | +20 | +40 | — | +30 |
| 记事阁 | -10 | -20 | +30 | +30 | — |

## 4. 真相引擎（Truth Engine）

系统**不保存** `矿难真相 = X`，只保存**证据集合**：

```json
{
  "id": "E4",
  "source": "工程师手记",
  "time": "战前",
  "reliability": 0.88,
  "conclusion": "有人提前下令延迟抽水",
  "faction": "中立",
  "tampered": false,
  "contradicts": ["E1", "E2"]
}
```

- 玩家每获得一个证据 → 更新"认知状态"。
- 不同证据组合 → 不同结论 → 不同可选项与结局。
- **认知状态永远存在不确定性**（`certainty < 1.0`）。

完整规则与证据见 `docs/truth-tree.md`；数据见 `data/evidence.json`。

## 5. 与叙事的关系
- 选择 / 信任 / 真相三层，让"冷战 + 历史真相"从**背景**变成**玩法**。
- 但**优先级**：先做一条完整、可读的主线；系统是增强，不是前提。
