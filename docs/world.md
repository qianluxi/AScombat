# 世界规则（World）

> 本文件是世界的**唯一事实源**。设定素材与现实原型见根目录 `世界设定扩展.md`。
> **本次修订（据专家意见）**：主题压缩为"1 核心 + 2 副"；真相收敛为"三层"；删除"幕后超级阴谋集团"。

## 1. 地理与阵营

- 整个星球**没有海洋，只有湖泊**（含咸水湖）。文明依托湖与河而生。
- **火之联盟（火盟）**：多火山，表层水紧张、地下水丰富、温泉多。共和国制，设总统与各部。
- **水之联盟（水盟）**：类千湖之国，超大型湖泊与毛细血管般的河网，水运发达。君主立宪制，保留无实权国王，首相执政。
- 其余国家：或从属两盟，或不参加任何联盟、名义中立。中立的商业城邦结成**环湖十一城**。
- 时代水平：类似地球**工业革命以前**，农业与手工业为主，生产力不发达。
- 两盟关系：长期冷战式对抗；二十年前因金属矿脉爆发大战，损失惨重，签停战协议，**矿脉永久封存**，纸面停战五十年。

## 2. 四条铁律（最新修订，务必遵守）

### 2.1 反 1:1 影射（独立世界原则）
- 现实原型（冷战、不结盟运动、Gladio、COCOM、卡廷等）只作**幕后骨架**。
- **不允许任何现实国家完整映射到火盟或水盟。** 火盟可同时借用不同侧面；水盟同理。
- 正文不出真实名词、不出现可对应的人名地名事件。

### 2.2 三层信息结构（**收敛为三层**）
> 作者内部可以知道六层细节，但**读者的阅读体验只有三层**。

| 层 | 读者的理解 | 说明 |
|---|---|---|
| **第一层** | 矿难并不像课本写的那么简单。 | 卷一末～卷二 |
| **第二层** | 当年有人**故意延迟救援**。 | 卷二～卷三 |
| **第三层** | 真正可怕的不是某一个人，而是**一群人为了各自的利益，让一个意外变成了战争**。 | 卷四揭晓 |

**纪律**：写任何场景前先问"此刻读者理解到第几层"，不要提前泄露第三层。
> 密约、工程队、译者、军工、走私链等，**全部降为支撑证据**，不再单独成为一层。

### 2.3 魔法 = 操纵，而非创造
见 `docs/magic.md`。一句话：**没有魔法能凭空制造物质或无限能源。**

### 2.4 信息不可靠，但叙事可靠（**新增**）
- 读者可以不知道"当年谁先下令"；
- 但读者**必须确信**："矿难确实发生过""有人确实延迟了救援"。
- **绝不能让读者觉得"作者自己也不知道真相是什么"。** 不可靠的是**史料**，不是**叙事本身**。

## 3. 无国籍的族群（风光系的政治命题）

火、水两系人口多且集中，故能建国；**风、光两系人口稀少且散落全球，从未形成国家。**

本项目对风光系的定位**不是"第三个超级阵营"**，而是：

> **一群无法形成国家的人。**

- 世界秩序由**国家**构成——那么**没有领土的族群**，究竟算什么？
- 他们能否拥有**政治权利**？谁来代表他们？
- 两种回应：
  - **明风会**：不谈建国，只求生存与和平。
  - **启明兄弟会**：主张必须建国，否则永远是待宰的少数。
- 核心冲突（由云舒承载）：**当两盟真的开始和解，风光系依然没有位置。**

## 4. 综合魔法大学

- 单系魔法学院各国皆有；**综合性魔法大学**能教授各系并有**研究职能**，只存在于不结盟国家，全世界仅**五所**。
- 主角就读的**镜湖学宫**位于环湖十一城中的"真中立城"，是五所之一，也是火、水、风、光学生**唯一能平等共处**的地方。
- 学宫允许火、水两系学生**跨系合作**——这正是蒸汽机只能诞生于此的制度前提。

## 5. 主题（压缩为 1 核心 + 2 副）

- **核心主题**：**人如何在一个被历史和政治塑造的世界里，重新认识"敌人"。**
- **副主题一**：真相并不天然带来和平。
- **副主题二**：技术本身不能决定未来，使用技术的人才决定未来。

## 6. 关于"幕后阴谋"的处理（**重要修订**）

旧稿中有"跨境共谋集团"的设定，**现予删除或大幅削弱**。

- 矿难的真相**不是**："某秘密组织设计矿难 → 控制双方 → 制造战争"。
- 而是：

```
自然事故
  → 有人延误救援
  → 有人错误判断
  → 有人害怕承担责任
  → 有人利用事故
  → 有人伪造证据
  → 战争爆发
```

> **没有一个人真正计划好这一切，但每个人都做了一点"看起来合理"的事，最终共同制造了灾难。**
> 这比"幕后大反派"更真实，也更有文学力量，并与"一整套把所有人变成零件的制度"这一主题高度一致。

- **御用炼金局与暗流商会不是同一个集团。** 它们只是**利益偶有重叠的独立势力**，各自逐利，从未统一步调。
