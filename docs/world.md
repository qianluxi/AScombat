# 世界规则（World）

> 本文件是世界的**唯一事实源**。设定素材与现实原型见根目录 `世界设定扩展.md`。

## 1. 地理与阵营

- 整个星球**没有海洋，只有湖泊**（含咸水湖）。文明依托湖与河而生。
- **火之联盟（火盟）**：多火山，表层水紧张、地下水丰富、温泉多。共和国制，设总统与各部。
- **水之联盟（水盟）**：类千湖之国，超大型湖泊与毛细血管般的河网，水运发达。君主立宪制，保留无实权国王，首相执政。
- 其余国家：或从属两盟，或不参加任何联盟、名义中立。中立的商业城邦结成**环湖十一城**。
- 时代水平：类似地球**工业革命以前**，农业与手工业为主，生产力不发达。
- 两盟关系：长期冷战式对抗；二十年前因金属矿脉爆发大战，损失惨重，签停战协议，**矿脉永久封存**，纸面停战五十年。

## 2. 三条铁律（最新修订，务必遵守）

### 2.1 反 1:1 影射（独立世界原则）
- 现实原型（冷战、不结盟运动、Gladio、COCOM、卡廷等）只作**幕后骨架**，用于设计"模式与心态"。
- **不允许任何现实国家完整映射到火盟或水盟。** 火盟可同时借用美式联邦工业、苏式国家科研、日式资源焦虑、德式技术教育等侧面；水盟同理。
- 正文不出真实名词、不出现可对应的人名地名事件。

### 2.2 三层信息结构
所有设定按"读者何时知道"分为三层：

| 层 | 名称 | 内容示例 | 何时揭露 |
|---|---|---|---|
| **L1** | 玩家/读者知道 | 火水两盟敌对；二十年前打过仗；大学在中立国；矿脉被封 | 第一章即可交代 |
| **L2** | 逐渐发现 | 两盟课本不一样；矿难有疑点；有人在查矿脉；某些教授知道更多；两盟都在秘密发展武器 | 推动剧情，二至四章 |
| **L3** | 真正的真相 | 矿难＝误判 → 信息操纵 → 政治利用 → 嫁祸 → 战争的**多层叠加**，没有单一凶手 | 第六章才揭晓 |

**纪律**：写任何场景前先问"此刻读者在第几层"，不要提前泄露 L3。

### 2.3 魔法 = 操纵，而非创造
魔法的硬约束见 `docs/magic.md`。核心一句话：**没有魔法能凭空制造物质或无限能源。**

## 3. 无国籍的族群（风光系的政治命题）

火、水两系人口多且集中，故能建国；**风、光两系人口稀少且散落全球，从未形成国家。**

本项目对风光系的定位**不是"第三个超级阵营"**，而是：

> **一群无法形成国家的人。**

由此产生的政治命题，比"受歧视"高级得多：

- 世界秩序由**国家**构成——那么**没有领土的族群**，究竟算什么？公民？难民？资源？
- 他们能否拥有**政治权利**？谁来代表他们？
- 两种回应：
  - **明风会**：不谈建国，只求生存与和平（传信、赈灾、行医、教书）。
  - **启明兄弟会**：主张必须建国，否则永远是待宰的少数。

> 这条线是故事的思想纵深之一，不是动作线索。它没有简单答案。

## 4. 综合魔法大学（世界观的关键装置）

- 除传统学校外，设有专门魔法学校：多为**单系学院**，各国皆有。
- **综合性魔法大学**：既能教授各系魔法，又有**研究职能**——研究如何用魔法提高生产力、造福人民。
- 这类大学**只存在于不结盟国家**，全世界仅**五所**，是火盟与水盟长期想拉拢、控制的对象。
- 主角就读的**镜湖学宫**位于环湖十一城中的"真中立城"，是五所之一。
- 学宫既招魔法生，也招**非魔法生**进入机械、自然哲学等研究科——这是主角得以入学的通道（见 `docs/characters.md`）。

## 5. 主题

> **知识、技术和历史，在政治环境下会变成什么？**

- 政治线、历史线、校园线、科技线最终汇聚到**同一核心事件（矿难）**。
- 蒸汽机不是"科技树升级"，而是**剧情本身**：它同时是可救人的水泵与可杀人的动力。
- 结局不写"科技带来和平"，而写：**技术与真相的走向，由使用它的人和制度决定。**
