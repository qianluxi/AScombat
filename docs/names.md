# 命名规范（Names）

> 全仓库**专名**统一按本表。仿《银河英雄传》做法：**从某种语言衍生出该语言本身并不存在的名字**。
> 本次采用**俄语衍生**与**英语衍生**两大语区。

## 1. 语区分配

| 语区 | 归属 | 命名特征 |
|---|---|---|
| **俄语衍生** | 火之联盟 | 男名多以 -n/-r/-m 结尾；姓氏用 -ov/-ev/-in/-sky/-ko |
| **英语衍生** | 水之联盟 | 名多取自然／古英语名；姓氏用 -well/-ford/-ton/-ley/-mere |
| **混合** | 哈洛米尔十一城、瓦雷林学宫等中立方 | 两语区混用 |
| **混血杂糅** | 风光系（无国籍者） | 一名取俄、一姓取英（或反之）——**名字本身即"不属于任何一国"** |

> 说明：两大阵营（火之联盟 / 水之联盟）与功能性机构（御用炼金局、自然哲学会）沿用**描述性通名**，同《银英》的"帝国 / 同盟"，不另取专名。

## 5. 保持不变（描述性通名，非专名）

- 火之联盟 / 火盟、水之联盟 / 水盟
- 御用炼金局、自然哲学会
- 换谍渡口、真中立城／骑墙城／亲火城／亲水城／待价而沽城（城市职能标签）
- 技术名词：汽相、余汽、汽忆效应、汽爆、汽化纹、汽晶、汽工 / 双相工程师、储汽装置、泄汽阀
- 魔法四系：火、水、风、光

## 6. 新增专名的规则

1. 先定**语区**（看所属阵营）。
2. 用该语区的词尾习惯造一个"像那种语言、但不存在"的名字。
3. 中文写作时用**音译**（如 扎列夫），并在本表登记语源。
4. 风光系新角色用**混血名**，以强化"无国籍"。
