# 剧情结构：四卷 31 章（Chapters）

> 从"平铺七章"到"三幕七章"再到**四卷 31 章**。全文约 **11 万字**。
> **本次修订（据专家意见）**：史料不再机械按奇偶章交替；第一卷以**具体生活场景**开场；结局去掉"科技直接带来和平"的童话因果。

## 1. 主题（1 核心 + 2 副 + 1 隐喻）

- **核心主题**：**人如何在一个被历史和政治塑造的世界里，重新认识"敌人"。**
- **副主题一**：真相并不天然带来和平。
- **副主题二**：技术本身不能决定未来，使用技术的人才决定未来。
- **隐喻**：**有些力量不是属于任何一方的，它只会在不同的人愿意共同工作时出现**——即"汽相"（见 `docs/vapor.md`）。

## 3. 叙事穿插规则（修订）

**不要机械执行"单数主线 / 双数史料"。** 史料**在主线需要它的时候才出现**，且形式随剧情演进：

```
前期：教科书摘录（官方口径）
中期：老兵口述（在场者的记忆）
后期：工程师手记（残缺的直接证据）
高潮：三种史料互相冲突
终章：主角亲眼看到真相
```

> 判定标准：**这一段史料，是否让读者更关心当下的人？** 若否，删掉或改写。

## 4. 第一卷的写法（修订）

**不要让第一卷变成设定说明书。** 用"让读者撞上世界"的方式开场。

> **示例·第一章开场**：
> 陶砾第一次进学宫食堂。他发现一半学生吃**火烤**的食物，一半学生吃**水煮**的食物；两边甚至为"什么才是真正的烹饪"吵了起来。
> ——读者由此自己得出：原来火盟和水盟，连吃饭都是意识形态。

- **"火烤 vs 水煮"必须重点保留**：它是全书的**日常层**，让世界真实。
- **结尾回扣**：火盟学生学会做水煮菜，水盟学生学会烤东西。作者不必写"两族和解"，读者自己会懂。

## 5. 汽相：这个世界独有的"蒸汽"（修订）

**本世界的"蒸汽"不是现实蒸汽，而是火、水魔法共同作用产生的"汽相"。** 它不是第五种魔法，而是**两种属性合作后的涌现现象**。完整设定见 `docs/vapor.md`。

**核心四阶段**（取代原先的"蒸汽七阶段"）：
1. **发现汽**：水火同步 → 汽相。
2. **驯汽**：汽相 → 推动活塞。
3. **循环汽**：汽相 → 循环系统（**主角的突破**：解决"汽相循环稳定性"）。
4. **理解汽**：明白汽相不是火的力量、也不是水的力量，而是**两者关系产生的力量**。

**要点**：
- 过去几千年，人们会烧水、也会用水魔法，但**没人把两种魔法以特定相位叠加**——所以主角发现的不是"蒸汽"，而是"**汽相可以被驯化**"。
- 发明是**火、水、机械三个领域的人共同完成**，不是天才的灵光一闪。
- **军工路线（追求更强 / 汽爆）vs 主角路线（追求更稳 / 低压循环）**——主角的第一台水泵不是最强的，而是第一台**可靠**的。

## 6. 汽相失稳：与矿难焊死

- 矿难不是"有人炸毁原型机"，而是**汽相第一次失控（汽爆）**——一场失败的实验（见 `docs/history.md`）。
- **证据不止于文件**：矿井痕迹、金属腐蚀（汽化纹）、机器留下的压力周期、甚至**声音**，都是历史证据。
- **守夜人韩砧的证词**："那天不是先塌的，先变的是声音。"——年轻人后来研究汽相才明白：他说的是**汽相失稳**。老兵口述与科学技术在此汇合。

## 7. 结局的因果（修订）

**不要让"主角发明水泵"直接导致和平。** 更真实的因果链：

```
主角发明水泵
   ↓（并未解决政治问题）
火水学生共同完成水泵
   ↓
双方第一次共同获得实际利益
   ↓
矿区人民开始使用
   ↓
共同利益扩大
   ↓
一部分普通人开始不再愿意战争
   ↓
政治变化开始出现
```

### 结尾画面（删除"引领星球进入蒸汽文明时代"）
> 第一台水泵工作。矿井里的水开始下降。
> 有人第一次看到：**二十年前困住那些人的水，正在被抽出去。**
> 火系学生和水系学生一起，把碑立起来。
> 远处，工厂的烟囱冒出第一缕蒸汽。
> **但两盟边境，仍然有军队。**

### 首尾呼应（汽相的三次诞生）
- **第一次诞生（失败）**：二十年前的矿难——水是死亡的一部分。
- **第二次诞生（成功）**：主角的水泵——水与火共同成为救人的力量。
- **第三次诞生（社会）**：火水年轻人的合作。
> **二十年前，水是死亡的一部分；二十年后，水与火共同成为救人的力量。**
> 不是"消灭水"，而是"**学会与水相处**"。
