# 历史：真实史 vs 各方版本（History）

> 本项目的历史**没有唯一文本**。同一事件，在火盟、水盟、中立城、民间传说中各不相同。
> 主角的任务不是"找到正确的那本"，而是**在互相矛盾的史料中作出自己的判断**。

## 1. 核心事件：矿难与大战

### 1.1 真实发生的事情（L3，第六章揭晓）
> 不是单一凶手的罪案，而是**五层叠加**：

1. **误判**：矿区排水系统老化，本就存在隐患。
2. **信息操纵**：两盟强硬派各自掌握情报却按需筛选、延迟上报。
3. **政治利用**：有人下令"延迟抢救"，把可控事故推向不可控。
4. **嫁祸**：事故后双方各自编造对方破坏的版本。
5. **借机开战**：强硬派需要一个既成事实，好毁掉正在推进的"湖区共管"和谈，垄断矿脉与新兴的汽动技术。

> 更深一层：**没有恶魔，只有一整套把所有人变成零件的制度**——两盟强硬派与军工势力（御用炼金局、暗流商会前身）构成跨境共谋集团。战后这张网延续至今。

### 1.2 火盟官方版本（L1 主打 / 被歪曲）
> "水盟见死不救，甚至破坏我军抽水设备，蓄意制造矿难。我们是被迫自卫的受害者，最终守住了矿脉尊严。"
- 教材里的关键词：牺牲、复仇、守卫。
- 抹去：延迟抢救的命令、共管密约、汽动原型。

### 1.3 水盟官方版本（L1 主打 / 被歪曲）
> "火盟为独占矿脉，故意制造事故并嫁祸我们。我们是被泼脏水的一方。"
- 与火盟版本**处处镜像**，双方人民各自坚信自己版本的"常识"。
- 抹去：同样存在的强硬派、同样的情报筛选。

### 1.4 中立城 / 大学版本（L2，相对冷静但不完整）
> "双方都有责任，这是一场悲剧性的误会。"
- 看似公允，实则**回避了共谋与密约**；中立城为了自保，也选择性沉默。
- 影射：连"正义的第三方"也会为大局掩盖历史。

### 1.5 民间传说 / 家族记忆（最不可靠也最动人）
- 矿工家属的口述、歌谣、纪念仪式——情绪浓、细节多，但夹杂美化、遗忘与自我安慰。
- 例：支线人物"沈祈（被抹去的译者）"的家族记忆，有**三个互相矛盾的版本**。

## 3. "真相树"

矿难真相由一系列**证据节点**构成，每个节点有来源、可信度、所属阵营、是否被篡改。完整图见 `docs/truth-tree.md`，机器可读版见 `data/evidence.json`。

> **设计要点**：系统/作者不保存"矿难真相 = X"，只保存一组**互相矛盾、带可信度的证据**，由主角（与读者）自行拼合。
