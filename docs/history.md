# 历史：真实史 vs 各方版本（History）

> 本项目的历史**没有唯一文本**。同一事件，在火盟、水盟、中立城、民间传说中各不相同。
> 主角的任务不是"找到正确的那本"，而是**在互相矛盾的史料中作出自己的判断**。
> **修订（据专家意见）**：删除"幕后共谋集团"；真相收敛为三层；译者支线降权。

## 1. 核心事件：矿难与大战

### 1.1 真实发生的事情（L3，卷四揭晓）

> **矿难的物理起点，是一场技术事故；它之所以变成战争，是因为一群人的私心恰好叠加。**

**物理层（技术事故）**：
```
矿区地下"热水脉"→ 天然汽相
  → 抽水系统当时正在处理异常汽相
  → 研究人员发现汽相压力异常
  → 有人为保住实验数据，下令延迟撤离 / 延迟抢救
  → 汽相失稳 → 汽爆
  → 矿难
```

**社会层（政治灾难）**：
```
有人延误救援  （担心停产 / 报喜不报忧 / 等待上级）
  → 有人错误判断  （误以为可以控制）
  → 有人害怕担责  （掩盖、修改记录）
  → 有人利用事故  （强硬派需要一个开战的既成事实）
  → 有人伪造证据  （双方各自编造对方破坏的版本）
  → 战争爆发
```

> **没有一个人真正计划好这一切，但每个人都做了一点"看起来合理"的事，最终共同制造了灾难。**
> 官方称"敌方破坏原型机"；真相是**一场失败的实验**，然后被人利用。
> 这比"有人炸毁原型机"更真实，也更有文学力量。

### 1.2 读者的三层理解（呈现纪律）
| 层 | 读者理解 | 出现时机 |
|---|---|---|
| 第一层 | 矿难不像课本写的那么简单 | 卷一末～卷二 |
| 第二层 | 当年有人故意延迟救援 | 卷二～卷三 |
| 第三层 | 可怕的不是某个人，而是一群人为各自利益让意外变成战争 | 卷四 |

> 密约、工程队、译者、军工、走私链——**全部是支撑证据，不是独立的层。**

### 1.3 火盟官方版本（被歪曲）
> "水盟见死不救，甚至破坏我军抽水设备，蓄意制造矿难。我们是被迫自卫的受害者。"
- 关键词：牺牲、复仇、守卫。抹去：延迟抢救、"看起来合理"的种种私心。

### 1.4 水盟官方版本（被歪曲）
> "火盟为独占矿脉，故意制造事故并嫁祸我们。"
- 与火盟版本**处处镜像**，双方人民各自坚信自己版本的"常识"。

### 1.5 中立城 / 大学版本（相对冷静但不完整）
> "双方都有责任，这是一场悲剧性的误会。"
- 看似公允，实则回避了具体的人与具体的选择；中立城为自保也沉默。

### 1.6 民间传说 / 家族记忆（最不可靠也最动人）
- 矿工家属的口述、歌谣、纪念仪式——情绪浓、细节多，但夹杂美化、遗忘与自我安慰。

## 2. 译者支线（降权）

> **不要让"被抹去的译者"变成第二本小说。**

- 她/他只承担一个作用：**证明两盟曾经有过另一种可能**——二十年前，本来可以不打了。
- **不为揭露更大的阴谋**；为**悲剧意义**而存在：战争并非不可避免。
- 呈现由重转轻：家族遗物中的几页纸、一段歌谣、一句祖母的喃喃。
- 例：战前，中立城译者**叶莲娜·克尔**曾传递"湖区共管"和谈文本，发现条款会牺牲矿区与中立城；她试图泄露，遂被抹去。**她的消失没有改变历史，只留下一个"如果"。**

## 4. 真相树
矿难真相由一系列**证据节点**构成，每节点有来源、可信度、所属阵营、是否被篡改。见 `docs/truth-tree.md` 与 `data/evidence.json`。

> **设计要点**：系统/作者**不保存**"矿难真相 = X"，只保存一组**互相矛盾、带可信度的证据**，由主角（与读者）自行拼合。
