# 核心人物设定（Characters）

> **纪律：核心人物压缩到 6 人（＋父辈一代）。不再增加人物数量。**
> 让这 6 个人承载整个世界；剧情由**人物关系**驱动，而不是由设定驱动。
> 每人**"最初目标"与"真正目标"必须不同**——这是人物推动剧情的前提。
> 命名均为提案，可替换。

---

## 1. 塔连·扎列夫（主角）

| 项 | 设定 |
|---|---|
| 年龄 | 17 |
| 魔法属性 | **火系（天资平庸）** |
| 出身 | 火盟·卡缅卡，矿区小镇，乡下少年 |
| 家庭 | 父亲杰米扬·扎列夫是矿区排水工程师，二十年前死于矿难；家里对"那座矿"讳莫如深 |
| 外貌 | 手上有老茧与烫疤，皮肤晒得黑，衣着土气 |
| 性格 | 务实、沉默、动手强；对大词与宏大叙事本能排斥 |
| **最初目标** | 学一门手艺，毕业回镇上修机器、让家里不再缺水 |
| **真正目标** | 弄清楚"父亲到底是什么人"，以及自己信的那套历史是不是真的 |
| 最害怕什么 | 发现自己最敬的人其实是"坏人"；以及有一天自己也会像大人一样说谎 |
| 最大的缺点 | 固执、认死理；一遇情感问题就闭嘴 |
| 秘密 | 随身带着父亲唯一的遗物——一枚旧矿灯，从不给别人看 |
| 对主角第一印象 | ——（本人） |
| 与主角关系变化 | ——（本人） |
| 最终选择 | 公开技术，但坚持"先让矿区用上"；把选择的权力交还普通人 |
| 人物结局 | 没有成为救世主；成为一个"愿意承认不确定、仍然向前"的年轻人 |

> **他不是天才。** 地质、魔法、机械、政治都只是"一般"。他唯一的长处是：**非常熟悉普通人的生活**——为什么乡下缺水、为什么机器坏了没人修、为什么战后粮食一直贵。所以他造出蒸汽水泵时，想到的不是"改变世界"，而是"**这东西要是能把矿井的水抽出去，我家那边是不是也能用？**"

### 塔连·扎列夫的人物弧线（全书骨架）
```
相信父辈 → 相信课本 → 怀疑课本 → 怀疑所有人
→ 甚至怀疑"真相" → 理解成年人为什么撒谎
→ 拒绝继承上一代的敌我观 → 自己做出选择
```

## 2. 玛伦·阿什韦尔（水系朋友）

| 项 | 设定 |
|---|---|
| 年龄 | 17 |
| 魔法属性 | 水系（娴熟） |
| 出身 | 水盟·航运世家，在中立城有生意 |
| 家庭 | 父亲科尔温·阿什韦尔被火盟指为矿难"战争罪犯"，家族声名受损 |
| 外貌 | 整洁、冷淡、衣着考究 |
| 性格 | 理性、严谨、嘴硬心软 |
| **最初目标** | 成为优秀工程师，远离家族阴影 |
| **真正目标** | 证明父亲不是战争罪犯 |
| 最害怕什么 | 真相反而证明父亲**确实有罪**——她怕的不是"被冤枉"，而是"真的有罪" |
| 最大的缺点 | 傲慢；习惯把情感问题当成技术问题 |
| 秘密 | 她私藏着一份对父亲不利的档案，却一直不敢打开 |
| 对主角第一印象 | "一个乡下来的火盟人"，轻视 |
| 与主角关系变化 | 竞争 → 合作（水火造汽）→ 并肩 → 因父亲问题决裂 → 和解 |
| 最终选择 | 与塔连·扎列夫一同公开部分真相，接受"父亲既非英雄、也非纯粹罪犯" |
| 人物结局 | 与塔连·扎列夫共同署名的技术报告；与家族保持距离，但不再撕裂 |

> **她与塔连·扎列夫是对称的一对**：一个火盟少年，一个水盟少女，各自的父亲都被对方阵营指为罪人。两人第一次真正对话的核心是：**"我们的父辈，究竟谁在撒谎？"**——这是全书最重要的人际关系之一。

## 3. 雷恩·卡尔德（风/光系朋友）

| 项 | 设定 |
|---|---|
| 年龄 | 18 |
| 魔法属性 | 风系 |
| 出身 | 风光系，随温德林会流浪长大，无国无籍 |
| 家庭 | 可能出身奥里安兄弟会边缘；家人散落各地 |
| 外貌 | 轻快，随身背一个信囊 |
| 性格 | 开朗、消息灵通、外热内冷 |
| **最初目标** | 借学宫混一张"能通行两盟的文书"，好找份活 |
| **真正目标** | 为风光系争一个**属于自己的国家**，哪怕很小 |
| 最害怕什么 | 两盟和解了，风光系依然没人在乎 |
| 最大的缺点 | 用玩笑掩盖认真；可以为理想做危险的事 |
| 秘密 | 与奥里安兄弟会有联系 |
| 对主角第一印象 | 觉得这火盟乡下人"有意思，也好骗" |
| 与主角关系变化 | 朋友 → 分歧（和解 vs 建国）→ 亦敌亦友 → 相互理解，但道路不同 |
| 最终选择 | 不加入任何一方；推动"风光系自治权"写入和约 |
| 人物结局 | 开放式，可能是下一代的伏笔 |

> **他不是"受歧视的少数族群"这么简单。** 他要的是一个国家。而塔连·扎列夫要的是两盟和解。**当两盟真的开始和解，风光系仍然没有位置**——这条矛盾，是全书最锋利的思想冲突之一。

## 4. 叶戈尔·塔尔霍夫（机械教授）

| 项 | 设定 |
|---|---|
| 年龄 | 五十余 |
| 魔法属性 | 火系（工程化应用） |
| 出身 | 火盟工匠世家 |
| 家庭 | 有学生在御用炼金局任职 |
| 性格 | 务实、固执、信奉"工程师只管把东西造出来" |
| **最初目标** | 教好学生，做出一台真正能用的机器 |
| **真正目标** | 用机器证明"技术可以中立" |
| 最害怕什么 | 自己发明的东西，最终变成杀人的武器 |
| 最大的缺点 | 政治天真；用"技术中立"回避立场 |
| 秘密 | 早年曾与御用炼金局合作，后因分歧退出 |
| 对主角第一印象 | 欣赏那双有老茧的手 |
| 与主角关系变化 | 师生 → 合作者 → 因"技术该不该公开/军用"分歧 → 最终站到学生一边 |
| 最终选择 | 支持公开，同时接受"公开也会被军用"的代价 |
| 人物结局 | 与自然哲学会共同托管技术；晚年始终不安 |

> 他代表**技术中立主义**：科学只管发明，不问政治。然后他必须面对——**自己造的东西，可能成为武器。**

## 5. 伊沃·马腾（历史教授 / 安纳尔会成员）

| 项 | 设定 |
|---|---|
| 年龄 | 四十余 |
| 魔法属性 | 无魔法（纯学者） |
| 出身 | 中立城 |
| 性格 | 冷静、多疑、克制 |
| **最初目标** | 教好历史，整理史料 |
| **真正目标** | 让真相被更多人知道，**同时保护还活着的人** |
| 最害怕什么 | 真相被再次利用，成为开战的借口 |
| 最大的缺点 | 为了"保护"而隐瞒，结果成了他反对的那种人 |
| 秘密 | 手里握着一份可能害死人的证据，一直没公开 |
| 对主角第一印象 | 觉得他太天真 |
| 与主角关系变化 | 亦师亦友 → 因隐瞒被主角质疑 → 最终共同承担 |
| 最终选择 | 公开，但设置"冷却期"与匿名保护 |
| 人物结局 | 留在安纳尔会，成为新档案的守门人 |

> 他代表**真相主义**，却亲手示范了"真相主义者的困境"：**公开会害人，隐瞒会背叛理想。**

## 6. 格罗兹·拉金（科尔东守夜队队长）

| 项 | 设定 |
|---|---|
| 年龄 | 五十余 |
| 魔法属性 | 火系（已衰弱） |
| 出身 | 火盟矿区，战中一代老兵 |
| 家庭 | 老兄弟多已战死；他养着几个残兵 |
| 性格 | 粗粝、讲义气、现实 |
| **最初目标** | 守住禁区这份活，把老兄弟养到死 |
| **真正目标** | 让死去的人"不是白死"——哪怕只是一句真话 |
| 最害怕什么 | 自己当年做的事被清算，连累一帮兄弟 |
| 最大的缺点 | 关键时刻优先自保 |
| 秘密 | 当年他执行/目睹了"延迟抢救"的命令，并收过封口钱；他记得矿井里的声音——**"那天不是先塌的，先变的是声音。"** |
| 对主角第一印象 | "又一个来送死的毛头小子" |
| 与主角关系变化 | 阻挡 → 保护 → 出卖（为了兄弟）→ 倒戈（交出日志） |
| 最终选择 | 交出证据、出庭作证，承担后果 |
| 人物结局 | 可能入狱或被害；他的证词是压垮谎言的关键 |

> **全书最具文学张力的人物。** 他同时拥有战争经历、矿难记忆、老兵身份、走私经历、保护主角与背叛主角的可能。**读者始终无法简单判断他是好人还是坏人。**
>
> **他的"证词"不是政治阴谋，而是声音**："那天不是先塌的，先变的是声音。"——年轻人不懂，直到主角研究汽相才明白：他说的是**汽相失稳**。**老兵口述史与科学技术，在这一刻合为一体。**

## 9. 译者支线（降权处理）

> **不要让"被抹去的译者"变成第二本小说。**
> 她/他只承担一个作用：**证明两盟曾经有过另一种可能**——二十年前，本来可以不打这一仗。

- 不为揭露更大的阴谋；**为悲剧意义**而存在。
- 呈现方式由重转轻：家族遗物中的几页纸，一段歌谣，一句祖母的喃喃。
- 她的存在，让"战争并非不可避免"这一主题有了具体的、失去的面孔。
