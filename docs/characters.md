# 人物设定（Characters）

> **命名均为提案，可替换。** 原则：**先定主角，再定 6–10 个核心角色，让这些人物承载整个世界**，而不是一开始设计几十个人。

## 1. 主角：陶砾

| 项 | 设定 |
|---|---|
| 姓名 | **陶砾**（砾：碎石。取自矿区小镇黑砧镇） |
| 年龄 | 17 |
| 出身 | 火盟·黑砧镇，矿区工人与技工之子 |
| 魔法属性 | **无魔法者**（约 80% 的沉默多数之一） |
| 入学身份 | 镜湖学宫·机械与自然哲学科（中立综合大学唯一的非魔法技术通道） |
| 性格 | 务实、固执、动手能力极强、不善言辞；对"课本上的宏大叙事"天生怀疑 |
| 初始目标 | **很普通**：成为一名能把魔法与机械结合的工程师，做出"不靠天赋也能用"的机器 |
| 初始政治立场 | 近乎没有立场——一个只想学好手艺的乡下少年 |

### 主角的个人问题（故事的情感核心）
- 父亲**陶衡**是矿区的排水工程师，死于二十年前的矿难。
- **火盟教材**：父亲是为救人而牺牲的**英雄**。
- **水盟教材**：父亲是下令延迟抽水、制造矿难的**战犯**。
- 陶砾从小只信火盟版本；进入学宫后，他第一次接触到水盟版本与其他证据。
- **于是"历史问题"突然变成了"我父亲的问题"——宏大主题落在了一个具体的人身上。**

### 成长弧线
```
只想做个好工程师
   → 学术问题（矿脉排水）
   → 历史疑点（父亲的两种版本）
   → 政治（两盟与共谋集团）
   → 战争阴影
   → 选择：技术与真相，公开到什么程度
```
> 主角**不是救世主**。他改变世界的起点，是一台想让矿井不淹水的机器。

## 2. 核心角色（建议 9 人 + 1 历史人物）

| # | 姓名 | 阵营/属性 | 功能 | 多义性 |
|---|---|---|---|---|
| 1 | **陶砾** | 火盟·无魔法 | 主角 | — |
| 2 | **沐昭** | 水盟·水系 | 主角的水盟同伴，航运世家出身，谨慎理性，起初轻视火盟 | 傲慢却善良；家族与密约有关 |
| 3 | **云舒** | 风系·明风会背景 | 开朗、善传信、情报灵通；三系黏合剂 | 行会的"中立"其实两难 |
| 4 | **晞罗** | 光系（稀有） | 敏感孤僻，掌握"显影"能力（可鉴伪），是拼合证据树的关键 | 被神化也被排斥；或有隐瞒 |
| 5 | **祁冶 教授** | 机械系（火盟出身） | 带主角做蒸汽机；主张技术公开 | 与御用炼金局有旧 |
| 6 | **祝临 教授** | 历史系（中立） | 史料引路人，多疑，与记事阁有往来 | 也选择性沉默过 |
| 7 | **玄彻 教授** | 神秘教授 | "萨哈罗夫式"人物：曾设计毁灭性机械，今转向和平研究 | 真心悔悟，还是自我救赎？**始终存疑** |
| 8 | **韩砧** | 矿脉守夜人老兵 | 禁区线核心人物，提供"史一"；既救过主角也可能出卖他 | 灰色，读者始终难判 |
| 9 | **裴烛** | 记事阁成员（公开派） | 抄书人，推动真相公开；中段"意外"身亡 | 其死因本身成为谜 |
| 10 | **燧勉** | 火盟·火系（强硬派后代） | 潜在对手，天资高、代表旧秩序 | 未必是恶人，只是"信的版本不同" |

### 历史线人物
| 姓名 | 身份 | 说明 |
|---|---|---|
| **沈祈** | 中立城译者（战前，已失踪） | 支线核心。发现"湖区共管"密约隐藏条款，欲泄露而被抹去。其家族记忆有三个版本；可能与沐昭或某同伴沾亲。 |

## 3. 人物承载的世界
> **不要让世界靠旁白介绍，而让人物把世界带出来。**
- 火盟：陶砾、祁冶、燧勉。
- 水盟：沐昭。
- 风光系（无国）：云舒、晞罗。
- 中立/学术：祝临、玄彻、镜湖学宫。
- 灰色地带：韩砧、裴烛、暗流商会。
- 历史：沈祈、陶衡。
