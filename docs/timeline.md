# 记事年表（Timeline）

## 纪年约定
- **大战前 N 年**：以大战爆发为界，向前纪年。
- **停战 N 年**：以停战协议签署为界，向后纪年。
- **当前 = 停战 20 年**（主角入学之年）。
- 叙事线标记：**【主线】**（当下）｜**【史一】**守夜人老兵（可信度低）｜**【史二】**两盟官史（低，互相矛盾）｜**【史三】**工程师手记（高但残缺）｜**【支线】**沈祈（被抹去的译者，真伪夹杂）。

## 三代人的位置（下笔时用于定位）
- **战前一代**：研究队工程师、沈祈、两盟强硬派——故事里的"史"。
- **战中一代**：矿脉守夜人、老记者、记事阁老一辈。
- **主角一代**（停战 20 年左右出生者）：陶砾及其同伴——**唯一没有直接背负战争的一代**，也是唯一有可能超越父辈的一代。
