# 汽相与汽动技术（Vapor）

> **本文件回答一个问题：这个世界的"蒸汽"，为什么不是现实世界的蒸汽。**
> 汽相是全书第二条主线（技术线）的核心，也是整部小说的**隐喻**。它不是第五种魔法，而是**火与水两种属性合作后的"涌现现象"**。

---

## 0. 命名（从语言层就先告诉读者：这不是现实蒸汽）

| 场合 | 称呼 |
|---|---|
| 普通人俗称 | **蒸汽** |
| 工程师正式称 | **汽相** |
| 早期研究者 | **水火相变** |
| 矿工/民间俚语 | **沸灵** |
| 产物 | **余汽**、**汽忆效应**、**汽爆**、**汽化纹**、**汽晶** |
| 从业者 | **汽工**、**双相工程师** |
| 装置 | **储汽装置**、**泄汽阀** |

## 1. 汽相是什么

- 现实世界：水 + 热 → 水蒸气；热散 → 凝结为水。
- **AScombat 的汽相**：**水魔法与火魔法同时作用于水时，产生的一种暂时脱离普通"水—气"平衡的魔法相。**

三个关键点：

1. **携带魔法属性**：它不只是高温高压气体，本身带有"**推动物体恢复平衡**"的倾向——所以用它驱动汽缸特别有效。
2. **膨胀方向可被操控**：普通蒸汽只往低压处扩散；汽相可被**火魔法改变膨胀方向**。这使"水火合作"从道德口号变成**机械原理的一部分**。
3. **冷却后不立即复水**：先形成"**余汽**"（见 §3.2）。

## 2. 如何产生（四个必要条件，缺一不可）

```
水魔法   → 改变水的相态
火魔法   → 提供热 / 能量
机械结构 → 约束、捕获汽相
───────  两者魔法的相位与强度必须同步
```

> **这就是"为什么几千年没人发明蒸汽机"的答案**：
> 过去的人会烧水，也会用水魔法，但没人想到把两种魔法以**特定相位叠加**并用机械结构捕获。
> **主角发现的不是"蒸汽"，而是"汽相可以被驯化"。**

## 3. 汽相的性质

### 3.1 方向可控
火魔法可以改变汽相的膨胀方向。因此早期实验中，**水火法师分列机器两侧**：一侧生成汽相，一侧控制膨胀方向。

### 3.2 余汽与"余汽污染"
汽相冷却后**不直接变回水**，而先变成极短暂的"**余汽**"。余汽会：
- 附着在金属表面
- 形成薄雾
- **使某些魔法短暂失效**
- 让机械产生微小震动
- 在空气中缓慢消散

于是汽动机械会出现现实世界没有的问题——**余汽污染**。
解决之道不是普通冷凝，而是设计**泄汽阀**，把余汽泄出。这形成这个世界独有的机械美学。

### 3.3 汽忆效应
汽相经火魔法强化后，会**短暂"记住"最后一次受力方向**。即使火魔法停止，它仍会有一次**微弱的同向膨胀**。工程师称之为**汽忆效应**。
→ 汽动机不是简单的热机，而是**水火魔法耦合机械**。

### 3.4 失稳与三种事故
| 失衡 | 后果 |
|---|---|
| 火魔法过强 | **爆燃** |
| 水魔法过强 | **凝结** |
| 两者不同步 | **汽爆** |
> 汽爆瞬间可产生极大推动力——这是危险，也是军工垂涎之处。

### 3.5 视觉：近乎透明
现实蒸汽是白雾。汽相**近乎透明**，只有在特殊光线下才看得见——**空气像玻璃一样轻微扭曲**。
只有水火比例失衡时，才出现明显白雾。
→ 早期研究者甚至犯过错误："**看不见，所以以为没有汽。**"

### 3.6 听觉：玻璃杯缘的高频鸣声
汽相不是"嘶——"，而是**类似手指摩擦玻璃杯边缘的高频鸣声**。不同压力下音高不同，故**听声音就能判断机器状态**。
- 民间知识：**"机器开始唱第二个音的时候，离它远一点。"**
- 读者要到很后面才知道：那是**汽相失稳的前兆**。
- 早期**矿工比工程师更懂这个声音。**

## 4. 四阶段（技术史骨架）

| 阶段 | 内容 |
|---|---|
| **一·发现汽** | 水 + 火 → 汽相 |
| **二·驯汽** | 汽相 → 推动活塞 |
| **三·循环汽** | 汽相 → 循环系统（**主角的突破**） |
| **四·理解汽** | 人类终于明白：汽相不是火的力量，也不是水的力量，而是**两者关系产生的力量** |

> 老一代只能让汽相**推动一次**；主角解决了"**汽相循环稳定性**"，让它**循环**——这才是真正的汽动革命。

## 5. 汽动机械：循环系统

```
水 → 火 → 汽相 → 推动活塞 → 冷凝 / 余汽处理 → 回收水 → 再次加热 → 循环
```

- **第一代汽动**：能产生汽相，能推动一次，但**无法稳定循环**（余汽滞留、压力漂移）。
- **第二代汽动**：加入泄汽阀与循环结构，**第一台真正可靠的汽动机器**。
- **主角的水泵不是最强的机器，而是第一台"可靠"的机器。**

## 6. 两条路线：军工 vs 民用

| | 军工思路 | 主角思路 |
|---|---|---|
| 追求 | **更强**（最大压力 / 汽爆） | **更稳**（稳定低压循环） |
| 手段 | 储汽装置 → 把水火控制部分机械化 | 泄汽阀 + 循环结构 |
| 目的 | 武器 | 抽水、驱动、民生 |
| 后果 | 不再需要现场同时有火、水法师 | 第一台民用可靠汽动机器 |

> **储汽装置是关键转折**：它让汽动不再依赖"现场同时有火水魔法师"，于是**汽动技术真正变成武器**。这正是第二至三卷技术伦理冲突的来源。

## 7. 材料：汽化纹与汽晶

- 某些金属在长期承受汽相循环后，会形成特殊微观结构，工程师称"**汽化纹**"。
- 这种金属能**储存少量汽相状态**，即**汽晶**。
- **克制使用，不是俗套的魔法矿石。**
- **第一块汽晶**，很可能就是**当年矿难现场留下的实验材料**——主角在矿区发现它。

## 8. 新职业与教育：汽工 / 双相工程师

- 汽相需要水火**同时**操作，于是出现现实中不存在的职业：**汽工 / 双相工程师**。
- 他们**不是第五类魔法师**，而是**同时理解水与火的人**。
- 这将直接改变教育体系：单系学院之外，需要**跨系培养**——而镜湖学宫正是唯一允许火水同室的地方。

## 9. 政治后果：物理规律迫使合作

- 汽动技术**必须依赖两种魔法**：火盟想控制火系工程师，水盟想控制水系工程师，但**没有另一边就无法生产**。
- 因此汽动技术**天然迫使两个国家合作**——不是道德让他们合作，而是**物理规律**。
- 更进一步：过去，国家建立在**魔法属性**之上；如今**最重要的新技术却必须跨属性合作**。
  → 工业革命将逐渐冲击"**以魔法血统/属性为基础的民族政治**"。
  → 这才是真正意义上的"蒸汽革命"：它开始动摇"**国家为什么存在**"。

## 10. 隐喻：汽相是整部小说的核心

> **有些力量不是属于任何一方的，它只会在不同的人愿意共同工作时出现。**

- 火盟认为世界需要火；水盟认为世界需要水；两边互相排斥。
- 但**只有火与水同时存在、彼此约束，才产生汽相**。
- **火不是水的敌人，水也不是火的敌人；它们只有在彼此约束时，才产生第三种力量。**

### 汽相的"三次诞生"
1. **第一次诞生（失败）**：二十年前的矿难——汽相第一次失控，成了死亡的一部分。
2. **第二次诞生（成功）**：主角的水泵——水与火共同成为救人的力量。
3. **第三次诞生（社会）**：火水两族年轻人的合作——隐喻在人与人之间实现。

> 首尾呼应：**二十年前，水是死亡的一部分；二十年后，水与火共同成为救人的力量。**
> 不是"消灭水"，而是"**学会与水相处**"。

## 11. 与矿难的关系（把两条主线焊死）

- **矿区不是单纯的重要金属矿**，而是"**天然汽相实验室**"：地下存在一种特殊的**热水脉**，同时具备——
  - 地热
  - 高压地下水
  - 特殊矿物
  - 不稳定的魔法属性
- 这解释了：为什么两盟都争这里、为什么水火研究队在此实验、为什么汽动技术在此出现、为什么抽水如此重要、为什么矿难会发生。
- **矿难的物理起点**，正是**汽相第一次失控（汽爆）**——详见 `docs/history.md`。
