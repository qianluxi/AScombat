# 魔法系统（Magic）

> 修订目标：把"世界观设定"升级为**可运转的系统**，堵住"火盟缺水却不造水""火盟能量无限"等漏洞。

## 1. 基本法则

### 1.1 天赋与遗传（沿用原设定）
- 约 **20%** 的人口能使用魔法；能否使用**天生决定**，后天无法习得。
- 技巧与威力可经学习锻炼增强，但**不存在夸张的魔法**，多数人用魔法只为方便生活。
- 四系：**火、水、风、光**。每人**只能使用其中一系**。
- 遗传概率：
  - 同类魔法夫妻：90% 同类，10% 无魔法。
  - 魔法 × 非魔法：50% 该系，50% 无魔法。
  - 异类魔法夫妻（如 火 × 水）：40% 火，40% 水，20% 无魔法。
- 约 80% 的人**无魔法**——他们是这个世界沉默的多数，也是机械与工艺的主要劳动力。

### 1.2 第一原理：操纵，而非创造
- 魔法**只能操纵已存在的元素/能量**，**不能凭空创造物质或能量**。
- 因此：
  - 水魔法**不能凭空造水**，只能操纵已有的水（河、湖、地下水、湿地、空气中的水汽）。
  - 火魔法**不能凭空生能**，只能点燃、加热、操控已有的火焰与热量（需有可燃物或热源）。
- 这是全世界所有政治与地理格局的**物理基础**，不可违反。

## 2. 魔法的消耗（决定"为什么不是万能的"）

魔法消耗**两样东西**，缺一不可：

| 消耗 | 说明 | 耗尽后果 |
|---|---|---|
| **体力** | 施法消耗身体能量，与搬重物同源 | 脱力、昏厥 |
| **精神力（专注）** | 维持对元素的精确控制 | 注意力涣散、控制失败、反噬 |

- **环境约束**：施法还受**环境中该元素的多寡**限制。
  - 火魔法在暴雨、湿地、缺氧处大幅削弱。
  - 水魔法在干旱、高原、密闭处大幅削弱；从干燥空气中"榨水"代价极高、量极小。
  - 风魔法依赖气流与开放空间。
  - 光魔法依赖光源或有可用环境光。
- **过载风险**：长期超负荷使用会导致不可逆的"**枯脉**"（魔法能力衰退甚至丧失），是底层魔法劳工的常见职业病。
- **结论**：魔法是"放大器与工具"，不是"永动机"。它提高了人力上限，但**没有改变资源禀赋**——这保证了地理决定论仍然成立。

## 3. 四系详解

### 火系（人口最多，分布集中）
- 能做：点燃、加热、控温、冶炼助燃、操纵既有火焰。
- 不能做：凭空产生热量/能量。
- 文明后果：**火山热、燃料、金属冶炼、重工业**。火盟的强盛建立在"火山 + 燃料 + 火魔法助燃"之上。
- 弱点：依赖热源与燃料；缺水。

### 水系（人口最多，分布集中）
- 能做：操纵既有水体——引流、抽水、增压、净化、凝雾成滴（小量）。
- 不能做：凭空造水。
- 文明后果：**水运、水利、灌溉、水力机械**。水盟的强盛建立在"湖河 + 水运 + 水魔法操控"之上。
- 弱点：依赖既有水源；火盟地表水稀缺，水系魔法师在火盟"无米可炊"。

> **关键设定呼应**：火盟缺水，不是因为"没有水魔法师"，而是因为**水魔法也变不出水**，而火盟地表本就没有水。张力由此自洽。

### 风系（人口稀少、散落，无国家）
- 能做：操纵气流——传信、加速、隐蔽、搬运轻物。
- 特点：**唯一能低成本长距离传讯**的系别，故在情报、走私、通信上不可替代。
- 文明后果：风光系人群天然成为**跨境的信使、跑腿、走私网络与行会**（呼应明风会、挑夫帮）。

### 光系（人口稀少、散落，无国家）
- 能做：操纵光——照明、显影、误导（光学幻象）、信号。
- 特点：稀有，常被神化或排斥；也常被宫廷与宗教吸纳。
- 文明后果：光系人群多依附于他国权贵，**更难形成共同体**——这正是"无国籍族群"命题中最尖锐的一支。

## 4. 汽相：火与水的"涌现现象"（见 `docs/vapor.md`）

> **修订（据专家意见）**：本世界的"蒸汽"**不是现实世界的蒸汽**，而是一种火、水魔法共同作用产生的**魔法相——"汽相"**。
> 汽相**不是第五种魔法**，而是**两种属性合作后的涌现现象**。详细设定见 `docs/vapor.md`。

要点：
- 水魔法单独 → 水；火魔法单独 → 热；**两者同步作用于水 → 汽相**。
- 汽相**只属于"合作"**，不属于任何一个人——这是全书主题的物理学版本。
- 汽相**不是第五种魔法**，而是**两种属性合作后的涌现现象**——所以它**只属于"合作"**。
- **但要注意**：这只在"第一次被发现时"成立。一旦汽相被技术化（**储汽装置**），水火控制即可机械化，从而**摆脱现场合作**——于是分出**民用道路**与**军事道路**（见 `docs/vapor.md` §9）。
- 蒸汽机只能诞生在**允许跨系合作的中立大学**。

### 历史闭环
> **二十年前**：一支水火混编研究队已发现汽相，但在战前因失稳事故而埋没；
> **现在**：火水学生重新合作、重新发现汽相、重新面对矿难。
> ——这条闭环是全书的结构骨架（见 `docs/chapters.md` 与 `docs/vapor.md`）。
