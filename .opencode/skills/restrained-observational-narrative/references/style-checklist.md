# Style Checklist（按场景类型检查）

> 用法：**先判断场景类型，再取对应清单**。
> 不要拿"所有文学技巧"去套每一个场景——那会把日常、调查、技术场景都写成同一种节奏。
> 通用项每场都查；专项按类型查。

---

## A. 通用项（每个场景都查）

- [ ] 场景有明确的**焦点人物**，且只呈现他能观察、记忆、推断或听说的内容。
- [ ] 人物**没有掌握**当时不可能知道的信息。
- [ ] 场景开始时人物有**目标**，中途遇到**阻力**，结束时**发生了变化**（事件／关系／认知至少一项）。
- [ ] 不能分辨的信息被明确区分：亲眼所见 / 他人所述 / 当时推断 / 事后理解。
- [ ] 没有大段世界观说明；背景通过动作、物件、环境自然呈现。
- [ ] 情绪没有反复被直接命名；若有情绪词，符合人物与情境且未被过度解释。
- [ ] 意象/物件若重复，至少带来新事实、新理解或关系变化；否则删减。
- [ ] 没有为了悬念而牺牲因果逻辑，也没有让人物忽略他本该注意的明显证据。

---

## B. 日常场景（食堂／课堂／宿舍／校园）

> 目标：让偏见、习惯、能力、处境在**具体互动**中显现，而不是展示设定。
> 风险：写成"设定展示台"；或用力过猛，人人说半句话。

- [ ] 至少有一处**生活质感**细节（食物、器物、声音、气味、动作），且不刻意服务后续情节。
- [ ] 人物的**习惯或偏见**通过行动体现，而非由叙述者总结。
- [ ] 阵营差异（火烤 vs 水煮、红领/蓝领）以**行为**呈现，不由人物直接科普。
- [ ] 对话可以有直截了当、玩笑、争吵、明确拒绝——**不要求**全部都含蓄。
- [ ] 场景结束时，人物对他人或环境的**认识/关系**有细微变化（哪怕很小）。

---

## C. 调查场景（档案／证词／矿难线索）

> 目标：读者与人物一起，在有限证据下慢慢逼近真相。
> 风险：过早越过信息层级；或"整包"给出结论。

- [ ] 分清**事实 / 证据 / 解释 / 可信度 / 认知状态**，未把推断写成已证实。
- [ ] 证据**来自可追溯的来源**，且说明谁可接触、谁知晓其存在。
- [ ] 关键信息以**碎片或侧漏**方式出现（不完整交谈、矛盾叙述、缺页档案）。
- [ ] 场景**没有越过当前允许的认知层级**（矿难三层）。
- [ ] 人物对证据的**解释**可能出错，且有出错的具体理由（性格、立场、信息不足）。
- [ ] 新增线索是**后续可回收**的，不是为了氛围硬塞。
- [ ] 若读者会看不懂"证据意味什么"，补足必要信息（间接呈现 ≠ 隐藏一切）。

---

## D. 技术场景（汽相实验／机械）

> 目标：技术进步由实验、失败、观察、修正、合作推动。
> 风险：主角一次灵光一闪解决一切；或原理提前说尽、丢了谜团。

- [ ] 成果符合**当前汽相阶段**（发现汽 → 驯汽 → 循环汽 → 理解汽）。
- [ ] 现有**设备、材料、魔法能力**足以支撑（火魔法只操纵既有热源，不凭空生能）。
- [ ] 失败有**具体的技术原因**，不是"情节需要它失败"。
- [ ] 参与者的**专业能力互补**（火／水／机械），不是一个人包办。
- [ ] 技术进展**改变了人物关系或利益分配**（如两盟都想抢）。
- [ ] 早期只给**可观察现象与必要异常**，不提前解释全部原理；但也不违反已定技术规则。

---

## E. 对话专项（任何含对话的场景）

- [ ] 每段对话至少有一个作用：推动行动／暴露差异／造成误解／改变关系／提供或扭曲信息／迫使选择。
- [ ] 人物有**自己的交流目的**，不是替作者讲设定。
- [ ] 各人物的**说话方式有区别**（词、句长、直接/回避的程度）。
- [ ] **不是所有人都含糊**：含蓄要符合性格与情境压力，而非统一腔调。
- [ ] 朗读关键对话；若听着像作者在解释，重写。

---

## F. 交付前的最后三问

1. 这一场，读者**新知道了什么**？人物**新知道了什么**？（二者可以不同）
2. 结束时，**什么真的变了**？（若没变，考虑删/并/重设计）
3. 有没有哪一处技巧是**为技巧而技巧**？（有就删）
